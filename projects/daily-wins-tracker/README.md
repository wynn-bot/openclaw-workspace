# 🎯 Daily Wins Tracker

**Track small wins. Build unstoppable momentum.**

## What It Is

Daily Wins Tracker is a lightweight, beautiful web app that helps users build discipline, confidence, and consistency through celebrating small daily wins.

Unlike vague goal-setting apps, Daily Wins focuses on **immediate, tangible actions** — the micro-habits that compound into transformation.

## Features

✅ **Quick Win Entry** — Log wins in 3 seconds  
✅ **6 Categories** — Fitness, Learning, Social, Work, Health, Discipline  
✅ **Real-Time Stats** — Today's wins, streak counter, weekly progress  
✅ **12-Week Heatmap** — Visual momentum tracker (GitHub-style)  
✅ **Insights Dashboard** — Top categories, weekly trends, progress analytics  
✅ **Motivational Messages** — Rotating quotes + encouragement  
✅ **Confetti Celebrations** — Dopamine hit on every win logged  
✅ **CSV Export** — Download your data anytime  
✅ **Completely Offline** — Works without internet, saves locally  
✅ **Mobile-Responsive** — Designed for one-handed phone use  
✅ **Dark Mode** — Easy on the eyes, looks premium  
✅ **Zero Tracking** — All data stays on your device, no spyware  

## How to Use

### Online (No Download)
1. Open `daily-wins-enhanced.html` in any browser
2. Start logging wins
3. Watch your momentum build

### Mobile (Install as App)
1. Open on phone, tap "Share" menu
2. Select "Add to Home Screen"
3. App installs like a native app
4. Works offline, super fast

### Desktop
1. Download `daily-wins-enhanced.html`
2. Double-click to open
3. Pin browser tab
